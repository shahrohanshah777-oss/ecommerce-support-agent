# Order Status Meanings

Placed means the order has been confirmed and is being packed at the warehouse, and it can still be cancelled. Shipped means the package has been handed to the courier and a tracking link has been sent to the customer. Delivered means the courier has confirmed delivery, which starts the return window. Returned means the item has been collected and is awaiting quality check, while Refunded means the quality check passed and the refund has been issued.
