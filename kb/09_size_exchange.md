# Size Exchange Policy

Apparel and Footwear can be exchanged for a different size of the same product within 15 days of delivery, provided the item is unworn and still has its original tags. Each item can be exchanged only once, and only if the new size is in stock; otherwise the customer is offered a refund instead. The replacement ships only after the original item has been picked up, and size exchanges are free of charge. Beauty, Home and Electronics products are not eligible for size exchange.
